Email

This is a static site, so there is no server-side form. Email is the reliable channel:

excavationstation@gmail.com

Put the page URL or the topic in the subject line. For a guide correction, include the sentence you think is wrong. For a tool issue, include the browser and the steps. For a privacy request, write from the address you want associated with the request.

No street address is published. Public contact is also available as @Excavationpro on X and through issues on the relevant GitHub repository.

How to reach us

  • X / Twitter: @Excavationpro (primary public contact)
  • Project hub: Excavationpro GitHub Pages
  • GitHub: github.com/DeepSeekOracle, open an issue on the relevant public repo for tool bugs when possible
  • Site policies: Privacy · Terms · Editorial standards
  • Donate (optional tip, not required for replies): PayPal.me/ExcavationPro · Patreon / Excavationpro

For AdSense / content quality feedback on this domain, message via X with the page URL and a short note. We actively expand original guides on /guides/ and champion profiles under /champions.html.

What to include

For faster help, mention:

  • The page URL (for example /guides/… or /app.html)
  • What you expected vs what happened
  • Whether your question is about privacy, a guide correction, or a tool bug

Privacy requests

For privacy questions, read the Privacy Policy first, then contact via the channels above with subject line starting with “Privacy:”.

Business / advertising

AdSense is managed through Google’s publisher tools for this domain. We do not sell private user data. Editorial content is not available as undisclosed native advertising.

Please do not send passwords, private keys, or full API secrets. If you believe a skill or page creates a security risk, describe it at a high level and we will follow up.

Response expectations

This is a small independent publisher, not a support desk. Most messages get a reply within a few business days. A clear message with a URL and a reproducible step is much faster than a screenshot with no context. Abuse, spam, and requests to help with unauthorized access are ignored.

What not to send

Do not send passwords, API keys, private keys, or full logs containing personal data. If a security issue requires a sensitive detail, describe the class of issue and ask for a safer channel first.
