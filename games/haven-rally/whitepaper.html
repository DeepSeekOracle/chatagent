Haven Rally v1.1

Time-trial racer. One craft, one closed circuit, a ghost of your best run. No account. Local ledger. This page is the spec the live client follows.

Play Arcade Ledger

1. Loop

Countdown 3–2–1–GO. Three laps (endless: two). Pass sector gates in order. Crossing the start line with all sectors collected scores a lap. Beat the ghost. Post the card to this browser.

3. Physics (math first)

World x,z yards. Heading radians. Speed yards/sec. Craft stats: acc, vmax, turn, grip, boost.

Throttle adds acc. Drag is quadratic. Steering rate falls with speed. Grip caps lateral change; excess is drift (heading still turns, speed bleeds). Off the ribbon: grip × 0.32, speed bleeds hard. Boost multiplies acc while the meter lasts; meter recharges on-track only.

Nearest-segment project onto the densified loop gives along-track s and signed lateral. |lat| > width is off-track. Sectors fire when s crosses their fraction.

5. Crafts

One live chassis: Apex Mk I (Lattice GT). Procedural PBR model in carmodel.js — lofted body, clearcoat paint, five-spoke rims, gold wing, cyan DRLs. Garage is a studio turntable; Bay 02 and 03 stay locked until more models land. Old saves on Mira/Reed/Kai map to Apex.

IdRole
apexBase chassis. Balanced accel / grip / boost. The game is built around this mesh.

6. Ghost + ledger

Each heat records {x,z,h} samples. Best finish time per circuit|craft keeps the ghost. Ledger key lygo-haven-rally-v1 in localStorage. RESOURCE on the public page; this browser is the hall. No fake global board.

7. Studio surface

Title screen matches Lattice Golf: full-bleed Apex still, right panel, operator name, garage chip, mode cards, radio, PayPal.me/ExcavationPro + Patreon. Garage is a live 3D studio (drag to orbit). 2.5D Three.js follow-cam; 2D top-down fallback if WebGL fails.
