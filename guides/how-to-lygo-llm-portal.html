How to use the LYGO API Portal

By Justin Helmer · updated 16 September 2026 · Free

On this page Two products Connect an API (this page) Browser agent tools Download the FULL local console If Connect fails Disclaimer

Two products — keep them separate

https://chatagent.ca/portal/ is an API portal. You bring a free or paid key. This domain does not host a GPU.

FULL local LYGO LLM Console is a download. Your GGUF models, folders, SkillHub FULL, USB CLAW. That kit is not this webpage.

Connect an API (3 steps)

  1. Open chatagent.ca/portal/. Default provider is Groq (free tier) — get a key at console.groq.com/keys.
  2. Paste the key. It stays in this browser tab. GitHub Pages never receives it.
  3. Click Connect, then chat.

Also in the list: OpenRouter, Gemini, Cerebras, Hugging Face, Mistral, NVIDIA NIM, Cohere, SambaNova, LLM7, Z.ai, DeepInfra, Hyperbolic, Novita, SiliconFlow, DeepSeek, Together, Fireworks, OpenAI, Anthropic, Perplexity, GitHub Models, or any OpenAI-compatible URL.

Free-key roundup (limits change): Groq, Google AI Studio, OpenRouter :free models, Cerebras, Hugging Face, Mistral Free, NVIDIA NIM, Cohere trial. Full table on the portal.

Browser agent tools

Skills and 15 Δ9 champions are already on the page. Toggle them on/off in the left rail (same idea as the local console). Visitors cannot install or download skills here — that is the bonus of the online portal. The model uses skill_list / skill_read on enabled items only. Soul / Identity / Memory files ship with the portal (editable in your browser).

After Connect, browser tools: Wikipedia, page fetch, weather, time, calc, SHA-256, HN, arXiv, GitHub search, Wayback. Geolocation and clipboard ask you first.

Save session as… and Save notepad as… write a file wherever you choose (File System Access, or a download). Load session restores a JSON you saved. Attach file puts text into this chat only — nothing is uploaded to chatagent.ca.

No server disks. No GGUF scan. That is the local kit.

Download the FULL local console

If you want models on your machine:

  1. SkillHub — FULL LYGO LLM kernel
  2. Docs: lygo-llm-console.html
  3. ClawHub map: @deepseekoracle/lygo-llm-console

Windows: unzip, run the BAT, Scan, Boot a GGUF. Admin USB is a separate steward channel.

If Connect fails

Many vendors block browser CORS. Try Groq or OpenRouter first. Or use the local console, which talks to llama.cpp on 127.0.0.1.
