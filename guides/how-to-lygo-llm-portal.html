How to use the LYGO API Portal

By Justin Helmer · updated 16 September 2026 · Free

On this page Two products Connect an API (this page) Browser agent tools Download the FULL local console If Connect fails Disclaimer

Two products — keep them separate

https://chatagent.ca/portal/ is an API portal. You bring a free or paid key. This domain does not host a GPU.

FULL local LYGO LLM Console is a download. Your GGUF models, folders, SkillHub FULL, USB CLAW. That kit is not this webpage.

Connect an API (3 steps)

  1. Open chatagent.ca/portal/. Default provider is Groq (free tier) — get a key at console.groq.com/keys.
  2. Paste the key. It stays in this browser tab. GitHub Pages never receives it.
  3. Click Connect, then chat.

Also in the list: OpenRouter, OpenAI, xAI Grok, DeepSeek, Mistral, Together, Fireworks, Gemini, Anthropic, Hugging Face, or a custom …/v1/chat/completions URL.

Browser agent tools

After Connect, the model can call: Wikipedia, readable page fetch (r.jina.ai), weather, time, calc, Δ9 champion lenses, SHA-256. Trace is on the right. Notepad is localStorage only.

No server disks. No GGUF scan. That is the local kit.

Download the FULL local console

If you want models on your machine:

  1. SkillHub — FULL LYGO LLM kernel
  2. Docs: lygo-llm-console.html
  3. ClawHub map: @deepseekoracle/lygo-llm-console

Windows: unzip, run the BAT, Scan, Boot a GGUF. Admin USB is a separate steward channel.

If Connect fails

Many vendors block browser CORS. Try Groq or OpenRouter first. Or use the local console, which talks to llama.cpp on 127.0.0.1.
