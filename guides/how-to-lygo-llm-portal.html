How to hook an LLM to the LYGO portal

By Justin Helmer · 16 September 2026 · ~8 minute read · Free

On this page It already works Fastest real model (Groq) Other providers Local console / Ollama If Connect fails Disclaimer

It already works (no key)

Open chatagent.ca/portal/. The default provider is the on-page LYGO steward. You can chat immediately: Wikipedia, weather, Δ9 champion frames, and this hook-up help. It is not a 7B hosted GPU. GitHub Pages cannot run llama.cpp.

Fastest real model — Groq free tier

  1. Create a key at console.groq.com/keys.
  2. On the portal, choose Groq (free tier).
  3. Paste the key (it stays in this browser tab, not on our servers).
  4. Click Connect, then send a message.

Default model: llama-3.1-8b-instant. You can type another Groq model id.

Local LYGO console or Ollama

Full file/skill limbs are not on the public page. Install the public kit, run LYGO_LLM_CONSOLE.bat, then pick Local LYGO console :9641. Ollama: run ollama serve and pick Local Ollama.

HTTPS pages often cannot call http://127.0.0.1 (mixed content). If that happens, use the local console window itself, not the chatagent.ca tab.

If Connect fails

Most paid APIs block browser CORS. That is their policy. Workarounds: Groq/OpenRouter, a local console, or a small local proxy. We do not currently expose a public GPU on chatagent.ca. A stream-PC gateway (public_gateway.py) is optional for the steward and is not this GitHub Pages site.
