How to use the library

The guides are organized by the job you are trying to finish, not by keyword. Start with the lattice overview if the vocabulary is new. Go to the protocol stack if you need the reference layer. Use the handoff, redaction, and task-brief guides if you work with an agent day to day.

Each guide is written to stand alone. The links between them are there for the next question, not as a required reading order. If a page is missing the answer you need, the contact page is the route.

What makes a guide

A guide earns its place when it answers a question the tool cannot answer by itself: when to trust a result, how to check a claim, what to redact, how to hand work to another person. The pages here are checked against the tools they describe, and the limits are stated instead of hidden.

Start paths

New to the lattice: overview → protocol stack → public witness. Working with agents: task briefs → handoff playbook → done claims. Publishing safely: redact secrets → human review → safe skills. The path is a suggestion; the search box and the index are the map.

What is not here

There is no course, no paid tier, and no “one prompt that fixes everything.” The library is a set of public notes for people who want to check the work. If a guide is wrong, the correction is part of the library.

Corrections

If a guide is wrong, the correction is part of the library. Send the page and the sentence; the fix changes the page and the date.
