LYGO lattice overview for newcomers

By Justin Helmer · 8 August 2026 · No install required to understand this page

Start with the problem LYGO cares about

Creative and technical work with AI spreads across chats, repos, music portals, and agent skills. Context fragments. Trust decays. Mythic language can either clarify a system — or confuse newcomers. The LYGO project family tries to keep a living map of that work: documentation, free tools, champion personas, and optional deeper protocol experiments.

What you can ignore at first

You do not need kernel eggs, mesh gossip, or a full protocol stack checkout to use a champion prompt or to understand Continuum. Those deeper layers exist for operators who want modular, consent-gated infrastructure. Newcomers should stay on guides + free tools until curiosity pulls them further.

Values that show up repeatedly

  • Local authority — your machine and consent matter more than automatic cloud actions.
  • Receipts over vibes — hashes, ledgers, and capsules beat uncheckable claims.
  • Human remains the publisher — AI assists; you decide what ships.
  • Dual channels — public-safe surfaces vs engineer RAW packages, clearly labeled.

Suggested first hour

  1. Read About (5 minutes).
  2. Skim all fifteen champions (10 minutes).
  3. Follow summon steps on one real task (20 minutes).
  4. If you use coding agents, open the Continuum guide (15 minutes).
  5. Bookmark Contact and Privacy.

External hubs (optional)

  • eternalhaven.ca — broader Haven surfaces

  • lygo-protocol-stack on GitHub

Mythic names (Δ9, lattice, Lightfather) are part of the project’s creative system. On this publisher site we deliberately explain them in plain English so newcomers are not locked out.

A larger map (still optional)

Beyond chatagent.ca you may see Eternal Haven pages, music portals, protocol stack docs, and ClawHub skills. Treat them as neighborhoods of one city: you can visit one café without memorizing the subway. When a page assumes jargon, return here or to the resources hub.

Trust model in one paragraph

Public content is readable by anyone. Local tools should not exfiltrate your disk. Engineer FULL packages may be more powerful and require more care. Human consent gates write actions that matter. That is the lattice ethic we try to keep consistent.
