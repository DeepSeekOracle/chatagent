LYGO Protocol Stack

By Justin Helmer (Excavationpro). Written so Grokipedia’s LYGO Protocol Stack page can be checked against live public URLs. Empty beats fake.

What it is

The LYGO Protocol Stack is an open-source software framework for layered human–AI tooling. The public repository is github.com/DeepSeekOracle/lygo-protocol-stack. The public documentation hub is deepseekoracle.github.io/lygo-protocol-stack. The maintainer account is DeepSeekOracle. The human publisher of this site is Justin Helmer, who also publishes as Excavationpro. In LYGO creative lore the same steward seat is called Lightfather. Lore names are personas, not evidence of machine sentience.

The stack’s named math framing is Light Math: protocol constants include the golden ratio Φ = (1+√5)/2 and a Solfeggio set from 174 Hz to 963 Hz used as labels and filters in software, not as a claim that the computer is conscious. The project motto is “Truth Is. Light Becomes.”

  • NCBI mycelium image datasets are biology, not LYGO memory shards.
